# 밴드 비서

Gmail과 Google 캘린더를 ChatGPT로 정리해서 **샤오미 스마트 밴드 11**에 진동 알림으로 보내 주는 Google Apps Script입니다.
서버도, 안드로이드 앱 개발도 필요 없습니다. 코드 한 파일을 붙여넣고 설정만 하면 됩니다.

```
Google Apps Script (5분마다 자동 실행)
   ├─ Gmail · 캘린더 읽기
   ├─ ChatGPT로 요약 · 중요도 판단
   └─ 텔레그램 봇으로 전송
          ↓
   폰 텔레그램 앱 → Mi Fitness 알림 미러링 → ⌚ 밴드 진동
```

## 1. 무엇을 해주나요

| 알림 | 언제 | 밴드에 보이는 예시 |
|---|---|---|
| **아침 브리핑** | 매일 08:00~08:05 | `10/18(토) 아침 브리핑`<br>`· 10:00 팀 회의`<br>`· 14시 비 예보, 외부 미팅 우산 챙기기`<br>`· 남은 중요 메일 2개` |
| **중요 메일 알림** | 새 메일이 오면 (5분 간격으로 확인) | `[결제] ○○카드`<br>`이번 달 청구 금액 확인 필요` |
| **일정 리마인드** | 일정 시작 10분 전 | `13:00 ○○ 미팅`<br>`장소: ○○역 근처 카페`<br>`참고: 지난번 자료 피드백 받기로 함` |
| **출발 알림** | 장소가 있는 일정, 출발해야 할 때 | `지금 출발하세요 — ○○ 미팅`<br>`13:00 시작 · 대중교통 약 35분` |
| **메일 속 일정 감지** | 메일에 날짜·시간 약속이 있으면 | `메일에서 일정 발견`<br>`○○ 상담 10/22(수) 15:00`<br>`캘린더에 추가할까요?` |
| **저녁 마무리** | 매일 21:00~21:05 | `오늘 마무리 · 내일 미리보기`<br>`· 남은 일 3개`<br>`· 내일 첫 일정 09:30` |
| **남은 일 확인** | 저녁 마무리 직후 (최대 3개) | `남은 일 — 완료할까요?`<br>`[업무] 문서 검토 요청 (오늘)` |

**중요 메일 기준** (기본값, [설정](#5-설정-바꾸기)에서 변경 가능)
- 결제 · 청구 · 환불 · 카드 · 은행 · 세금 · 구독 갱신
- 업무: 동료 · 상사 · 고객 · 거래처, 채용 · 면접 · 계약
- 공공기관 · 학교 등에서 온 공식 안내나 서류 제출 요청
- 마감이 있거나 내 답장이나 조치가 필요한 메일

내 상황에 맞는 기준(예: 학교 공지, 특정 거래처)은 [`Local.gs`](#개인-값은-localgs에-따로-두기-추천)에 추가하면 됩니다.

광고, 뉴스레터, 프로모션, SNS 알림은 무시합니다.

## 3. 설치 (약 20분)

### 3-1. OpenAI API 키 발급 (PC)

1. [platform.openai.com](https://platform.openai.com) 로그인
2. **API keys** → **Create new secret key** → 이름 `band-assistant` → 생성
3. `sk-...` 키를 **바로 메모장에 복사**합니다. 창을 닫으면 다시 볼 수 없습니다.
4. **Billing**에서 크레딧 잔액이 있는지 확인합니다. 0이면 동작하지 않습니다.

### 3-2. 텔레그램 봇 만들기 (폰)

1. Play 스토어에서 **텔레그램** 설치 → 전화번호로 가입
2. 검색창에 **`@BotFather`** 검색 → 파란 체크가 있는 공식 계정 → **시작**
3. **`/newbot`** 입력
   - 봇 이름: `밴드 비서`
   - 봇 아이디: 영문, 끝이 `bot` (예: `my_band_helper_bot`). 이미 있으면 다른 이름으로 다시 입력
4. BotFather가 보내 준 **토큰**(`1234567890:AAH...`)을 복사해서 PC로 옮겨 둡니다. **비밀번호처럼 다루세요.**
5. 같은 메시지의 **`t.me/내봇아이디`** 링크를 눌러 **내 봇 채팅방**을 열고 **시작**을 누릅니다.
   - ⚠️ 채팅방 맨 위 이름이 **BotFather가 아니라 내 봇 이름**인지 확인하세요.

### 3-3. 위치 좌표 확인 (날씨용, PC)

구글 지도에서 집이나 회사를 **마우스 오른쪽 클릭** → 맨 위 숫자 `37.xxxx, 127.xxxx`를 클릭해 복사합니다.
앞 숫자가 위도(`LAT`), 뒤 숫자가 경도(`LON`)입니다.

### 3-4. Apps Script 프로젝트 만들기 (PC)

1. [script.google.com](https://script.google.com) 접속 → Gmail을 쓰는 그 계정으로 로그인
2. **＋ 새 프로젝트** → 맨 위 "제목 없는 프로젝트"를 눌러 이름을 `밴드 비서`로 변경
3. 이 저장소의 [`Code.gs`](Code.gs)를 열고 오른쪽 위 📋 **Copy raw file**
4. 편집기의 기존 코드를 **전부 지우고**(Ctrl+A → Delete) 붙여넣기 → **Ctrl+S**
5. 코드 맨 위 `CONFIG`에서 아래 값을 고칩니다:
   ```js
   ORIGIN: '서울특별시 ○○구 ○○로 123',  // 집 또는 회사 주소 (출발 알림 기준)
   LAT: 37.5665,                          // 3-3에서 복사한 위도
   LON: 126.9780,                         // 3-3에서 복사한 경도
   ```
   - `OPENAI_MODEL`: 기본값은 가장 저렴한 `gpt-5-nano`입니다. 내 계정에서 쓸 수 없으면 OpenAI **Playground** 목록에 있는 다른 저렴한 모델로 바꿉니다. 추론형이 아닌 모델(예: `gpt-4.1-mini`)이면 `OPENAI_REASONING_EFFORT`를 `''`로 비웁니다.
   - `DONE_LABEL`: 완료 표시에 쓰는 Gmail 라벨 이름과 **글자까지 똑같아야** 합니다 (기본값 `완료`).
6. **Ctrl+S** 저장

### 3-5. 프로젝트 설정 (PC)

왼쪽 세로 메뉴 **⚙️ 프로젝트 설정**에서:

1. **시간대** → `(GMT+09:00) 서울`
   - 이걸 안 하면 브리핑이 엉뚱한 시간에 옵니다.
2. 아래 **스크립트 속성** → **스크립트 속성 추가** → 두 개 입력 → **스크립트 속성 저장**

   | 속성 | 값 |
   |---|---|
   | `OPENAI_API_KEY` | 3-1의 `sk-...` 키 |
   | `TELEGRAM_BOT_TOKEN` | 3-2의 봇 토큰 |

### 3-6. setup 실행 (PC)

1. 왼쪽 **`< >` 편집기** → 상단 함수 드롭다운에서 **`setup`** 선택 → **▶ 실행**
2. **권한 검토** → 계정 선택 → **"Google에서 이 앱을 확인하지 않았습니다"** 화면이 나옵니다
   → **고급** → **밴드 비서(으)로 이동(안전하지 않음)** → 권한 **모두 선택** → **허용**
   - 내가 만든 스크립트라서 뜨는 정상적인 경고입니다.
3. 텔레그램에 **"밴드 비서 연결 완료"** 메시지가 오면 성공입니다.
   - 로그에 `봇에게 메시지를 보낸 뒤 다시 실행하세요`가 나오면: 내 봇 채팅방에서 **시작**을 누르거나 아무 말이나 보낸 뒤 **`connectTelegram`** 을 실행합니다.

### 3-7. 폰 설정

1. **Mi Fitness** → 아래 탭 **장치**(⌚ 아이콘, 세 번째) → **앱 알림**
   - 맨 위 **앱 알림** 스위치 켜기
   - **휴대전화 알림 미러링** 상태면 그대로 두면 됩니다 (텔레그램 포함 모든 알림 전달)
   - **알림 사용자 지정**을 쓰는 경우 목록에서 **텔레그램**을 켭니다
2. 폰 **설정 → 애플리케이션 → 텔레그램 / Mi Fitness → 배터리 → 제한 없음**
   - 알림 누락을 막아 줍니다.

### 3-8. 테스트

1. **밴드를 손목에 차고**, 폰 **화면을 끄고 잠급니다**.
   - "착용 시에만 알림"이 켜져 있으면 손목에 없을 때 울리지 않습니다.
   - 텔레그램 봇 채팅방이 화면에 열려 있으면 폰 알림이 뜨지 않아서 밴드도 울리지 않습니다.
2. PC 편집기에서 함수를 하나씩 골라 **▶ 실행**합니다:

   | 함수 | 기대 결과 |
   |---|---|
   | `testNotify` | 밴드 진동 + "밴드 비서 테스트" |
   | `testMorning` | 오늘 일정 · 날씨가 담긴 아침 브리핑 |
   | `testEvening` | 저녁 마무리 + (중요 메일이 있으면) "남은 일 — 완료할까요?" |
   | `testMail` | 최근 메일 중 중요한 것이 있으면 알림 |

3. 텔레그램 메시지의 **[✅ 완료]** 버튼을 누릅니다. **1분 안에** 버튼이 사라지고 "완료 처리했어요" 메시지가 오면 성공입니다.

🎉 **설치 끝!** 이제 자동으로 실행됩니다. 왼쪽 **⏰ 트리거** 메뉴에 `tick`(5분)과 `pollTelegram`(1분)이 하나씩 보이면 정상입니다.

## 4. 사용 방법

### 매일 하는 일은 없습니다
설치 후에는 알아서 돌아갑니다. 밴드가 울리면 확인만 하세요.

### 고정 버튼으로 물어보기
텔레그램 봇 채팅창 아래에 버튼 3개가 항상 떠 있습니다.

| 버튼 | 답 |
|---|---|
| **오늘 일정** | 오늘 일정 전체 + 오늘 날씨 |
| **내일 일정** | 내일 일정 전체 + 내일 날씨 |
| **남은 일** | 완료 안 한 중요 메일 목록(최대 10개) + 번호별 **✅ 1, ✅ 2…** 완료 버튼 |

- 1분마다 확인하므로 답은 **최대 1분 뒤**에 옵니다 ([왜 1분인가요?](#왜-바로-답하지-않고-최대-1분이-걸리나요)).
- **버튼을 누르고 폰을 잠그면** 답이 밴드로 옵니다. 채팅창을 보고 있으면 폰에만 표시됩니다.
- 버튼이 안 보이면 봇에게 아무 말이나 보내면 다시 나타납니다.
- 내 채팅방에서 온 메시지에만 답하고, 10분이 지난 메시지는 무시합니다.

### 버튼은 폰 텔레그램에서 누릅니다
밴드에는 알림 내용만 보이고, 버튼은 **폰의 텔레그램 메시지** 아래에 있습니다.

| 버튼 | 누르면 |
|---|---|
| **✅ 완료** | 그 메일에 Gmail `완료` 라벨이 붙고 읽음 처리 → 이후 남은 일 목록에서 빠짐 |
| **📅 추가** | 메일에서 찾은 일정을 구글 캘린더에 등록 (일정 제안 후 3일 지나면 만료) |
| **메일 열기** | 해당 Gmail 스레드 열기 (Gmail 앱이나 브라우저) |

- ✅ 완료와 📅 추가는 브라우저를 열지 않습니다. 누르면 **최대 1분 뒤** 처리되고, 누른 버튼이 메시지에서 사라지며 소리 없는 확인 메시지가 옵니다.
- 버튼을 여러 번 눌러도 메일·캘린더에 중복으로 반영되지 않습니다.

### Gmail 라벨로 직접 관리하기
- **`AI중요`**: 스크립트가 중요하다고 판단한 메일에 자동으로 붙입니다.
- **`완료`**: 직접 붙이거나 ✅ 버튼으로 붙입니다.
- **"남은 일"** = 최근 30일 안에 `AI중요` 라벨이 있고 `완료` 라벨이 없는 메일입니다.
- 중요하지 않은데 잘못 분류된 메일은 Gmail에서 `AI중요` 라벨을 떼면 남은 일에서 빠집니다.

### 출발 알림이 오는 조건
- 캘린더 일정의 **위치** 칸에 실제 주소나 장소명이 있어야 합니다.
- **대중교통** 기준입니다. 한국에서는 구글 지도의 자동차 길찾기가 지원되지 않습니다.
- 출발지는 **그날 바로 앞 일정의 장소**이고, 앞 일정이 없으면 `CONFIG.ORIGIN`입니다.
- 화상회의 링크처럼 주소가 아닌 장소는 건너뜁니다.

### 일시 정지 / 완전히 끄기
- **잠깐 멈추기**: 왼쪽 **⏰ 트리거** → `tick`과 `pollTelegram` 트리거 삭제. 다시 켜려면 `setup`을 실행합니다.
- **완전히 끄기**: 위와 같이 트리거 삭제 + 텔레그램 BotFather에서 `/deletebot`

## 5. 설정 바꾸기

`Code.gs` 맨 위 `DEFAULT_CONFIG`를 고치고 **Ctrl+S** 저장하면 다음 실행(최대 5분 뒤)부터 적용됩니다.

### 개인 값은 `Local.gs`에 따로 두기 (추천)
Apps Script 편집기에서 **파일 ＋ → 스크립트** → 이름 `Local`로 새 파일을 만들고, 바꾸고 싶은 항목만 적습니다.
```js
const LOCAL_CONFIG = {
  ORIGIN: '서울특별시 ○○구 ○○로 123',
  LAT: 37.xxxx,
  LON: 126.xxxx,

  // 기준을 바꾸려면 목록 전체를 다시 적습니다
  IMPORTANT_CRITERIA: [
    '결제·청구·환불·카드·은행 등 돈과 관련된 메일',
    '업무 메일: 동료·상사·고객·거래처',
    '아이 학교·학원 공지',
    '마감 기한이 있거나 내 답장·조치가 필요한 메일',
  ],
  CATEGORIES: ['결제', '업무', '학교', '기타'],
};
```
- `LOCAL_CONFIG`에 적은 값이 `DEFAULT_CONFIG`보다 우선합니다.
- 이렇게 해 두면 `Code.gs`를 새 버전으로 통째로 바꿔도 내 설정이 유지됩니다.
- 저장소의 `.gitignore`에 `Local.gs`가 있어서, 포크해서 써도 주소가 GitHub에 올라가지 않습니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `OPENAI_MODEL` | `gpt-5-nano` | 사용할 ChatGPT 모델 (2026년 10월 기준 가장 저렴) |
| `OPENAI_REASONING_EFFORT` | `minimal` | 추론형 모델의 생각 단계. 추론형이 아닌 모델이면 `''` |
| `MORNING_TIME` | `08:00` | 아침 브리핑 시각 |
| `EVENING_TIME` | `21:00` | 저녁 마무리 시각 |
| `DONE_LABEL` | `완료` | 완료 표시 Gmail 라벨 |
| `IMPORTANT_LABEL` | `AI중요` | 중요 메일에 자동으로 붙는 라벨 |
| `IMPORTANT_CRITERIA` | 결제·업무·공공·조치 필요 | 중요 메일 기준 (문장으로 자유롭게 추가 가능) |
| `CATEGORIES` | `결제, 업무, 공공, 기타` | 알림 제목 앞 `[분류]` 후보 |
| `NOT_IMPORTANT` | 광고·뉴스레터 등 | 무시할 메일 기준 |
| `ORIGIN` | 서울시청 | 출발 알림 기본 출발지 |
| `LAT`, `LON` | 서울시청 | 날씨 위치 |
| `REMIND_BEFORE_MIN` | `10` | 일정 몇 분 전에 알릴지 |
| `DEPART_BUFFER_MIN` | `10` | 이동 시간에 더할 여유 시간(분) |
| `MAX_DONE_PROMPTS` | `3` | 저녁에 "완료할까요?"를 보낼 최대 개수 |
| `STRIP_EMOJI` | `true` | 밴드에서 □로 깨지는 이모지를 알림 본문에서 제거 |

**예시: 쇼핑 주문 알림 빼기**
```js
NOT_IMPORTANT: '광고, 뉴스레터, 프로모션, SNS 알림, 마케팅 자동 발송 메일, 쇼핑몰 주문·배송 확인',
```

## 7. 문제 해결

실행 오류는 Apps Script 왼쪽 **☰ 실행** 메뉴에서 빨간 "실패" 항목을 누르면 볼 수 있습니다.

### 알림이 안 와요

| 증상 | 확인할 것 |
|---|---|
| 텔레그램에도 안 옴 | 실행 로그 확인 → `TELEGRAM_CHAT_ID`가 없으면 봇 채팅방에서 **시작** 후 `connectTelegram` 실행 |
| 폰 잠금화면에 텔레그램 알림이 안 뜸 | 텔레그램 봇 채팅방 위쪽 이름 → 알림이 켜져 있는지(🔕 해제), 폰 설정에서 텔레그램 알림 허용 |
| 폰에는 뜨는데 밴드가 안 울림 | ① 테스트할 때 **봇 채팅방이 열려 있지 않았는지** ② 밴드를 **차고** 있는지 ③ 밴드 🌙 방해 금지 해제 ④ 폰 설정 → 알림 읽기 권한에서 **Mi Fitness 허용** ⑤ Mi Fitness → 장치 → 앱 알림 켜짐 |
| 밴드에 □ 같은 깨진 글자 | `STRIP_EMOJI: true`인지 확인 |

### 실행 로그 오류

| 오류 | 해결 |
|---|---|
| `OpenAI 401` | API 키가 틀림 → 스크립트 속성 값 확인 (앞뒤 공백 주의) |
| `OpenAI 429` / `insufficient_quota` | 크레딧 부족 → Billing에서 충전 |
| `OpenAI 404` / `model ... does not exist` | `OPENAI_MODEL`을 Playground에 있는 이름으로 변경 |
| `텔레그램 sendMessage 실패 ... 401` | 봇 토큰이 틀리거나 재발급됨 → `TELEGRAM_BOT_TOKEN` 확인 |
| `텔레그램 sendMessage 실패 ... chat not found` | 봇 채팅방을 삭제·차단함 → 봇에서 **시작** 후 `TELEGRAM_CHAT_ID` 속성 삭제 → `connectTelegram` |

### 버튼이 안 돼요

| 증상 | 해결 |
|---|---|
| 버튼을 눌러도 1분이 지나도 반응 없음 | ⏰ 트리거에 `pollTelegram`이 있는지 확인 → 없으면 `showButtons` 실행 |
| 원인을 모르겠음 | 버튼을 누른 뒤 편집기에서 `testPoll` 실행 → 실행 로그에 봇이 받은 메시지와 오류가 나옵니다 |
| 채팅창 아래 고정 버튼이 없음 | `showButtons` 실행, 또는 입력칸 오른쪽 ⊞ 아이콘을 눌러 펼치기 |
| 예전 메시지의 버튼이 브라우저를 엶 | 예전 버전이 보낸 링크 버튼입니다. 새 메시지부터는 브라우저 없이 처리됩니다 |

### 왜 바로 답하지 않고 최대 1분이 걸리나요?
Apps Script는 상시 켜져 있는 서버가 아니라 정해진 간격으로 실행되는 방식이고, 가장 짧은 간격이 1분입니다.
텔레그램이 버튼 누름을 즉시 전달해 주는 방식(웹훅)도 있지만, Apps Script 웹 앱은 응답할 때 주소를 한 번 돌려 보내는(302 리다이렉트) 구조라 텔레그램이 실패로 보고 같은 요청을 반복해서 보낼 수 있습니다. 그래서 안정적인 1분 확인 방식을 씁니다.

### 시간이 이상해요
- 브리핑이 엉뚱한 시간에 옴 → ⚙️ 프로젝트 설정 → 시간대가 **서울**인지 확인
- 08:00 정각이 아니라 08:00~08:05 사이에 오는 건 정상입니다 (5분 간격 실행).

## 8. 알아둘 점 · 보안

**개인정보**
- 메일 제목과 본문 일부(최대 1,500자)가 분류를 위해 **OpenAI**로 전송됩니다.
- 요약된 알림은 **텔레그램 서버**를 거쳐 내 봇 채팅방으로만 전달됩니다.

**비용**
- mini급 모델이면 하루 수십 번 호출해도 **한 달 몇백~몇천 원 수준**으로 예상됩니다 (모델 단가에 따라 다름).
- Apps Script, 텔레그램, 날씨(Open-Meteo)는 무료입니다.
- 무료 구글 계정의 Apps Script 트리거 실행 시간 한도는 하루 90분입니다. 1분 확인(`pollTelegram`)은 한 번에 1초 안팎이라 여유가 있습니다.

**비밀 값 관리**
- 이 저장소에는 비밀 값이 없습니다. OpenAI 키, 텔레그램 봇 토큰, 채팅방 ID는 모두 **Apps Script 스크립트 속성**에만 저장됩니다.
- 코드를 포크하거나 고칠 때 키를 `CONFIG`에 직접 적지 마세요.
- 봇 토큰이 노출되면 BotFather에서 `/revoke`로 재발급하고 `TELEGRAM_BOT_TOKEN`을 바꿉니다.
- 예전 버전의 링크 버튼(토큰 포함)이 노출되면 스크립트 속성 `ACTION_TOKEN`을 삭제하고 `setup`을 다시 실행합니다.

**왜 ntfy가 아니라 텔레그램인가요?**
처음에는 ntfy.sh를 썼지만, ntfy 무료 서버는 **보내는 쪽 IP 기준**으로 하루 전송량을 제한합니다. Apps Script는 전 세계 사용자가 구글 서버 IP를 함께 쓰기 때문에 한도가 금방 소진됩니다(`429 daily message quota reached`). 텔레그램은 **봇 토큰 기준**으로 제한해서 이 문제가 없습니다.
